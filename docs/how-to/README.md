# DevHub How-tos

Task-oriented entry points for working in the DevHub ecosystem. Each how-to links to the owning component's authoritative procedures rather than maintaining a second copy of commands or configuration.

- [Create a repository](CREATE-REPOSITORY.md): choose its scope, enroll and roll out GitHub policy, and initialize project content.
- [Set up a code editor](SET-UP-CODE-EDITOR.md): VS Code settings, extensions, and Settings Sync; separate personal and work accounts; and Git identities and SSH authentication.
