# Git Guidelines

Use general best practices for Git and follow the common guidelines.

Specifically for Git, in addition to general best practices:

- **Commit policy:** Use conventional commits for commit messages.
- **Commit-message policy:** Do not add `Co-authored-by:` trailers to actual commits or copy-ready suggested commands.
- **Branch policy:** Follow the repository's branching strategy and naming conventions for feature, bugfix, and release branches.

Use the optional `git-commit` skill for additional commit procedures when available.

Use relevant available skills for additional procedures and references.
