# Network Commands

Practical networking commands with output explanations for connectivity checks, debugging, and inspecting network configuration.

> **Why these tool-specific pages are here:** I use these command-line tools frequently in my work, and they are practical instruments for learning and verifying networking fundamentals. Knowing how to inspect routes, query DNS, and capture packets helps explain what the protocols and architecture are doing. This is a curated, hands-on exception to DevHub's general tool-agnostic scope—not an attempt to document every vendor's networking stack.

See the tool projects' official docs for full options and version-specific behavior: [iproute2](https://www.kernel.org/pub/linux/utils/net/iproute2/), [BIND DNS utilities](https://bind9.readthedocs.io/), [tcpdump](https://www.tcpdump.org/manpages/tcpdump.1.html), [Wireshark/tshark](https://www.wireshark.org/docs/), and [iperf3](https://software.es.net/iperf/). Use a local `man` page where available.
