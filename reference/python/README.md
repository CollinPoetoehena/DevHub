# Python Reference & Best Practices

Reference documentation and guidelines for Python packages within the DevHub project. As mentioned in the [Reference README](../README.md), this section is not meant to be complete and contain all possible information, but rather provide a curated set of best practices and conventions used across the project. It follows DevHub's general [scope and tool-specificity design](../README.md#scope-and-tool-specificity): focus on reusable foundations, and use official documentation for comprehensive, current tool details.

For packaging Python projects, see [Python Packages Documentation](../../packages/Python.md).

> **NOTE:** Python is an intentional exception to the general preference for tool-agnostic reference material because it is used frequently in this project. This reference includes Python-specific examples, APIs, and conventions, while also explaining foundations such as programming practices, object-oriented programming, functions, exceptions, testing, and logging that can inform work in other languages. Apply the underlying ideas broadly, but consult official Python documentation for authoritative language and library details. Language-agnostic design principles (DRY, KISS, YAGNI, SOLID, Clean Architecture, etc.) are documented in [Coding & Software Engineering Principles](../Software_Engineering_Principles.md).
