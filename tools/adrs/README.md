# Tools Architecture Decision Records

These records index durable decisions for DevHub's shared automation. Each tool owns its implementation details and decision rationale; this index points to the records maintained beside the tool.

## Repository fleet management

The [repository-fleet ADR index](../repo/adrs/README.md) covers the Terraform and Python tool boundary, their shared inventory, and centralized fleet synchronization.

Follow the [central ADR guidelines](../../docs/GUIDELINES.md#architecture-decision-records-adrs) for scope, placement, and referencing decisions.
