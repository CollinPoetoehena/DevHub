## Notices

- [Earlier AI customizations](AI-CUSTOMIZATIONS.md): why broad, overlapping skills gave way to packaged roles, scoped instructions, and focused workflows.

---

## Practical lessons

- Keep project decisions, constraints, and useful procedures; link to authoritative sources for general knowledge instead of maintaining an encyclopedia.
- Record commands when their project-specific context matters, not as another general command reference to keep current.
- Learning does not create an obligation to record every fact. Document what helps future work, not an unbounded backlog of everything learned.
- Give guidance one appropriate home. Use instructions for conventions, agents for roles, and skills for reusable on-demand workflows—not skills-only policy dumps.

For active setup and shared guidance, start with [Using DevHub](../docs/USAGE.md).
