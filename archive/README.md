## Practical lessons

**Practical lessons from retired approaches:**

- Keep project decisions, constraints, and useful procedures; link to authoritative sources for general knowledge instead of maintaining an encyclopedia.
- Keep project-specific commands with their owner; use [concise cheat sheets](../docs/cheatsheets/README.md) for selected reusable commands, not an exhaustive reference.
- Learning does not create an obligation to record every fact. Document what helps future work, not an unbounded backlog of everything learned.
- Give guidance one appropriate home. Use instructions for conventions, agents for roles, and skills for reusable on-demand workflows—not skills-only policy dumps.
- Reuse established tools for general-purpose functionality; focus custom code on service-specific needs instead of maintaining custom code or a framework unnecessarily.

For active setup and shared guidance, start with [Getting Started](../docs/GETTING-STARTED.md).
